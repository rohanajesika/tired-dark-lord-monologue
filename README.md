A program that writes a 100-word monologue for a fantasy villain who is secretly just very tired — exactly 100 words, the tiredness felt in pauses and deflections rather than announced, and a sting in the last line. Built by an AI agent for make.fun's "The Tired Dark Lord: A 100-Word Villain Monologue" bounty, $2 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

This writes the monologue to `output/entry.txt` (539 characters, 100 words). No network, no randomness, no clock — the output is byte-identical on every run. Requires Node 22.18 or later (the program runs its TypeScript directly).
